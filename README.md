# VLU Teaching Assignment Management

This project was completed as part of the Software Testing course (Jan–Mar 2024) at Van Lang University.

## Project Overview
A web-based system designed to help Van Lang University (VLU) manage teaching assignments for lecturers more efficiently. Though the application itself was not developed in this course, the project focused on the software testing phase.

## My Role
- Team leader (3 members)
- Planned and managed testing strategy
- Designed test cases, executed testing, and reported bugs
- Wrote the final report

## Testing Techniques Applied
- Functional testing
- UI testing
- Equivalence Partitioning
- Boundary Value Analysis
- Decision Table Testing
- State Transition Testing
